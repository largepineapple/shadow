# 复盘与后续

工程难点：模型可选择动作，但规则阻断、时间授权与保存结果必须由代码掌控；幂等检查先于冲突检查，避免重复请求把自己的草稿当成新冲突；Windows 需要额外 IANA 时区包。

实际修复：首轮工具测试发现 tzdata 缺失与无 id 的已有排期被错误过滤；集成测试发现重复提交未进入 existing 分支。修复后重新运行全套。进一步补充并发重复保存、风险不可保存与 soft 调整测试。

后续用户重新授权 DeepSeek 测试，8 组 live 场景全部通过，包括正常、缺失、阻断、冲突、确认、重复、故障与候选再占用。实际接入发现默认思考模式拒绝 required 工具选择；关闭思考模式后成功。一次模型单工具格式错误经有界重试恢复，Trace 原样保留。固定场景的成功仍不能代表广泛模型可靠性。生产化之前需增加真实数据连接、鉴权、审计与草稿生命周期，当前范围不实现发布。
